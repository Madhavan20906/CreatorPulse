---
name: CreatorPulse demo mode
description: Why the hackathon MVP keeps the growth loop reliable without requiring external provider credentials.
---

CreatorPulse's demo path must remain fully runnable without an external LLM or platform OAuth credential. Deterministic scoring, collision detection, package generation, QA, and measurement are intentional rather than fake AI fallbacks; any future live provider should enrich reasoning without becoming a prerequisite for the judge demo.

**Why:** Built-in AI provisioning required an account upgrade and the user declined adding a personal provider key, so the reliable path must not depend on unavailable credentials.

**How to apply:** Keep provider-backed features optional and label demo data, simulated publishing, and deterministic generation honestly in the UI and submission docs.
